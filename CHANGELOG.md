# История версий

## v2.0.0

### Breaking changes

- Минимальные версии - PHP 8.3, Laravel 12. Laravel 10 и 11 сняты с поддержки, для них используйте `1.2.*`;
- В `signCms()` политика TSP по-умолчанию изменена с `TSA_GOST_POLICY` на `TSA_GOST2015_POLICY`,
  значения `TSA_GOST_POLICY` и `TSA_GOSTGT_POLICY` помечены устаревшими;
- Трейт `NcanodeHttpClient` переведён с Guzzle на HTTP-клиент Laravel - свойство `$client` теперь
  `Illuminate\Http\Client\PendingRequest` вместо `GuzzleHttp\Client`;
- Методы `signXml()`, `signCms()`, `verifyXml()`, `verifyCms()` и `extractCms()` могут выбрасывать
  `JsonException` при некорректных входных данных.

### Улучшения

- Поддержка Laravel 13 и PHP 8.5;
- Обновление `endroid/qr-code` до 6.0;
- Уровень статического анализа PHPStan повышен с 5 до 7;
- Обновление истёкших тестовых сертификатов;
- Обновление зависимостей и тестов.

### Исправления

- Идентификатор документа больше не теряется при сохранении заявки с файлами, переданными без `id`;
- `validate()` с указанием списка полей передавал в `Validator::make()` коллекцию вместо массива;
- Ошибка `json_encode()` больше не приводит к отправке пустого тела запроса в NCANode;
- Некорректные данные заявки в кэше возвращают ошибку вместо аварийного завершения запроса;
- Добавлена проверка результата `file_get_contents()` в команде `kalkan:install`.

- Добавлена возможность формирования сервисных ссылок с дополнительной защитой Bearer-токеном;
- Добавлена возможность переопределять маршруты через конфигурацию;
- Унификация API, расширенная документация по шагам реализации;
- Расширенный ответ при проверке статуса документа;
- Новые события `AuthAccepted`, `AuthRejected`.
